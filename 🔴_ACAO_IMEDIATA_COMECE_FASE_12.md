## 🚨 SE ALGO NÃO FUNCIONAR

**Problema: SQL query dá erro**
```
Solução: Copiar EXATAMENTE conforme em 💻_FASE_12_COMANDOS_PRONTOS.md
         Substituir valores placeholders:
         - COLE_SEU_CLINIC_ID_AQUI → seu clinic_id
         - COLE_SEU_PATIENT_ID_AQUI → patient_id existente
         Tentar novamente
```

**Problema: UI não renderiza dados**
```
Solução: Verificar se você está logado
         Verificar console (F12) por erros JavaScript
         Verificar se banco tem dados (execute SQL queries)
         Fazer refresh (Ctrl+Shift+R)
```

**Problema: Recebível não criado automaticamente**
```
Solução: Verificar se trigger está ativo (Teste 1.1)
         Verificar Supabase logs por erro de trigger
         Re-aplicar trigger manualmente se necessário
```
