# 🔐 GitHub Secrets Setup - Passo a Passo

## ✅ Tudo Que Você Precisa Fazer

### Passo 1: Ir para GitHub Settings

```
1. Abrir: https://github.com/Gesclinic/Gesclinic-Web
2. Clicar: Settings (no topo)
3. Clicar: Secrets and variables (sidebar)
4. Clicar: Actions (subsection)
```

### Passo 2: Adicionar Secrets (OBRIGATÓRIO)

**Secret 1: VITE_SUPABASE_URL**
```
Name: VITE_SUPABASE_URL
Value: https://seu-projeto.supabase.co
```

**Secret 2: VITE_SUPABASE_ANON_KEY**
```
Name: VITE_SUPABASE_ANON_KEY
Value: eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
```

Onde encontrar:
1. Ir para: https://app.supabase.com/
2. Selecionar seu projeto
3. Settings → API
4. Copiar "Project URL" → VITE_SUPABASE_URL
5. Copiar "anon public" → VITE_SUPABASE_ANON_KEY

---

### Passo 3: Secrets Opcionais (Para Auto-Deploy no Vercel)

Se quiser Vercel auto-deploy:

**Secret 3: VERCEL_TOKEN**
```
Name: VERCEL_TOKEN
Value: [Get from https://vercel.com/account/tokens]
```

**Secret 4: VERCEL_ORG_ID**
```
Name: VERCEL_ORG_ID
Value: [From Vercel project settings]
```

**Secret 5: VERCEL_PROJECT_ID**
```
Name: VERCEL_PROJECT_ID
Value: [From Vercel project settings]
```

---

## ✨ Resumo

Você PRECISA adicionar:
- ✅ VITE_SUPABASE_URL
- ✅ VITE_SUPABASE_ANON_KEY

Você PODE adicionar depois:
- ⭕ VERCEL_TOKEN, VERCEL_ORG_ID, VERCEL_PROJECT_ID

---

## 🔍 Verificar Se Foi Correto

Depois de adicionar os secrets:
1. Ir para: GitHub → Actions
2. Disparar um workflow manualmente
3. Verificar se env vars estão carregadas
4. Se passar, está certo!
