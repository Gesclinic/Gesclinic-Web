═══════════════════════════════════════════════════════════════════════════════

Flow quando usuário tenta criar agendamento:

1. Usuário clica "Salvar"
   ↓
2. Trigger BEFORE INSERT executa
   ↓
3. Trigger faz: auth.uid() → retorna UUID
   ↓
4. Trigger faz: SELECT clinic_id FROM users WHERE id = [auth_uid]
   ↓
5. Se retorna NULL → Erro "Usuário não tem clínica associada"
   ↓
6. Se retorna UUID → clinic_id é FORÇADO ✅

POSSÍVEIS DIAGNÓSTICOS
═══════════════════════════════════════════════════════════════════════════════

Cenário 1: auth.uid() retorna NULL
───────────────────────────────────
Erro: "Sem usuário autenticado. Sessão inválida."
Causa: Usuário não está autenticado propriamente
Solução: Logout + Login novamente, ou limpar localStorage


Cenário 2: auth.uid() é válido MAS não está em public.users
───────────────────────────────────────────────────────────
Erro: "Usuário [UUID] não tem clínica associada"
Causa: Usuário em auth.users MAS não migrado para public.users
Solução: Inserir usuário em public.users com INSERT manual


Cenário 3: Usuário está em public.users MAS clinic_id é NULL
──────────────────────────────────────────────────────────────
Erro: Igual Cenário 2
Causa: clinic_id não foi preenchido
Solução: UPDATE para preencher clinic_id


Cenário 4: Tudo OK, trigger funciona! ✅
──────────────────────────────────────────
Erro: NENHUM!
Log: NOTICE mostra clinic_id FORÇADO
Resultado: Agendamento criado com sucesso
