# 📋 GUIA RÁPIDO: CHECK-IN NA RECEPÇÃO

## ✅ Fluxo Completo do Check-in

### 🟢 Passo 1: Paciente Chega na Recepção
- Recepcionista recebe o paciente
- Pergunta o nome ou documento
- Localiza o agendamento na **Agenda**

### 🟡 Passo 2: Abrir Agendamento
- Na tabela de agenda, **clique no agendamento** do paciente
- OU ao passar o mouse, aparece o botão **✅ Check-in** na coluna STATUS
- Clique nele!

### 🔵 Passo 3: Drawer de Atendimento Abre
O drawerlateral mostra:
- ✨ **Status do agendamento** (badge colorida)
- 👤 **Dados do paciente** (nome, idade)
- 🕐 **Horário** (hora e duração)
- 📋 **Serviço** solicitado
- 💼 **Profissional** responsável
- 🏥 **Convênio/Plano** de pagamento
- 📝 **Notas** importantes

### 🟣 Passo 4: Botão Check-in
- Clique em **📍 Check-in** no drawer
- VAI ABRIR O FORMULÁRIO DE CHECK-IN com opções:
  - ✅ Validar/confirmar CPF
  - 📱 Confirmar/atualizar telefone
  - 📄 Capturar documentos (foto)
  - 💳 Processar convênio
  - ↔️ Liberar para atendimento

### 🟠 Passo 5: Após Check-in
- Paciente está pronto para atender
- Status muda para **"Em Atendimento"** (⏳)
- Profissional recebe no atendimento

---

## ⚡ Atalhos Rápidos

| Ação | Como Fazer |
|------|-----------|
| **Abrir agenda** | Clique em **AGENDA** no menu lateral |
| **Procurar paciente** | Use a barra de **Busca** ("Buscar paciente ou serviço...") |
| **Filtrar por horário** | Selecione a data no calendário |
| **Check-in rápido** | Passe o mouse no agendamento → clique **✅ Check-in** |
| **Ver detalhes completos** | Clique no agendamento para abrir drawer |

---

## 🎯 Status do Agendamento

| Status | Ícone | Significado | Ação |
|--------|-------|------------|------|
| **Agendado** | 🗓️ | Confirmado, aguardando presente | Check-in → Liberar |
| **Check-in** | 📍 | Em processamento | Validar dados |
| **Em Atendimento** | ⏳ | Paciente com profissional | Aguardar conclusão |
| **Compareceu** | ✔️ | Atendimento completo | Faturar |
| **Faltou** | ❌ | Paciente não compareceu | Remarcar/Cancelar |
| **Cancelado** | 🚫 | Agendamento cancelado | - |

---

## 💡 Dicas da Recepção

✅ **Sempre validar CPF** antes de liberar para atendimento  
✅ **Confirmar telefone** para futuras confirmações de WhatsApp  
✅ **Fotografar RG/CPF** para auditoria  
✅ **Verificar convênio** se há cobranças adicionais  
✅ **Liberar na hora certa** para não atrasar profissional

## ❓ Dúvidas Frequentes

**P: Paciente não aparece na agenda?**  
R: Procure em outra data ou verifique se o agendamento foi criado corretamente.

**P: Como remarcar agendamento?**  
R: Abra o agendamento → Clique **📅 Remarcar** → Selecione nova data/hora.

**P: Paciente quer cancelar?**  
R: Abra o agendamento → Clique **❌ Cancelar** → Confirme.

**P: Como marcar falta?**  
R: Status automaticamente vai para **Faltou (❌)** se paciente não comparece.
