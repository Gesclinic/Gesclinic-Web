## 🔍 Se Tiver Problema

### Problema: Código exibe como UUID
```
❌ SVC001abc123...
✅ CONS-INI-001
```
**Solução:** Verificar se `appointmentsApi.js` foi modificado.  
Ver: `📋_CODE_SNIPPETS_MUDANCAS_EXATAS.md` (seção 3)

### Problema: Convênio não aparece
```
❌ -
✅ Particular
```
**Solução:** Verificar se `payerName` prop foi adicionado ao ServiceListItem.  
Ver: `📋_CODE_SNIPPETS_MUDANCAS_EXATAS.md` (seção 2, ADICIONADO)

### Problema: Linha vazia no topo
```
❌ Linha com dados vazios
✅ Nenhuma linha vazia
```
**Solução:** Verificar se `useEffect` foi removido de `AppointmentUnitedModal.jsx`.  
Ver: `📋_CODE_SNIPPETS_MUDANCAS_EXATAS.md` (seção 2, REMOVIDO)

### Problema: Layout não alinha
```
❌ Colunas não alinhadas
✅ Grid 100px | 2fr | 1.2fr | 1fr | 60px
```
**Solução:** Verificar se grid CSS foi aplicado.  
Ver: `📋_CODE_SNIPPETS_MUDANCAS_EXATAS.md` (seção 1, grid)
