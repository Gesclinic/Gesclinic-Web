🔐 REGRA DE OURO: LIBERAÇÃO
═══════════════════════════════════════════════════════════════════════════════

Para LIBERAR = 3 condições:

  1️⃣ CHECKLIST 100% COMPLETO
     ├─ Dados cadastrais conferidos ✅
     ├─ Serviço correto ✅
     ├─ Profissional correto ✅
     └─ Convênio/Pagamento OK ✅

  2️⃣ FINANCEIRO RESOLVIDO
     └─ Guia gerada OU Pagamento registrado ✅

  3️⃣ STATUS PERMITE
     └─ Não é CANCELADO, FALTA, FINALIZADO ✅

  SE TODAS = TRUE → ✅ BOTÃO VERDE FUNCIONA
  SE ALGUMA = FALSE → ❌ BOTÃO CINZA BLOQUEADO

📞 DÚVIDAS?
═══════════════════════════════════════════════════════════════════════════════

P: Posso usar em outro lugar?
R: Sim, reutilizável em qualquer lugar dentro de /clinica

P: Como funciona o bloqueio?
R: Se checklist < 100% OU financeiro != OK → botão cinza (desabilitado)

P: Profissional consegue forçar?
R: Não. Código JavaScript governa (não CSS). Sem dados = invisível para ele

P: Como personalizar itens do checklist?
R: Edite CheckinChecklist.jsx na função checklistItems

P: Qual é o banco de dados?
R: Supabase (appointments table)
