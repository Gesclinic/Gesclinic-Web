## ✅ ETAPA 6: VALIDAR DADOS CONVERTIDOS

Após executar migration, no Supabase SQL Editor, cole estas queries:

### Query 1: Verificar Coluna Criada
```sql
SELECT column_name, data_type 
FROM information_schema.columns 
WHERE table_name = 'appointments' 
AND column_name = 'official_status'
LIMIT 1;
```
✅ Resultado esperado: Uma linha com official_status | appointment_official_status

### Query 2: Contar por Novo Status
```sql
SELECT official_status, COUNT(*) as quantidade
FROM appointments
WHERE official_status IS NOT NULL
GROUP BY official_status
ORDER BY quantidade DESC;
```
✅ Resultado esperado: 8 status com contagens

### Query 3: Verificar Conversão de Legados
```sql
SELECT DISTINCT booking_status_legacy, official_status, COUNT(*)
FROM appointments
WHERE booking_status_legacy IS NOT NULL
GROUP BY booking_status_legacy, official_status
ORDER BY COUNT(*) DESC;
```
✅ Resultado esperado: Mapeamento claro de status antigos → novos

### Query 4: Verificar Índices
```sql
SELECT indexname 
FROM pg_indexes 
WHERE tablename = 'appointments' 
AND indexname LIKE '%status%';
```
✅ Resultado esperado: 3 índices criados
