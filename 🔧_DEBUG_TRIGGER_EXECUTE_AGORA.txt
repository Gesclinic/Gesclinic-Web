SE AINDA NÃO FUNCIONAR:


Opção A: Verificar auth.uid() vs users.id
  1. Em Supabase Dashboard, execute:
     SELECT auth.uid() as auth_uid;
  2. Anote o UUID retornado
  3. Agora execute:
     SELECT id, email, clinic_id FROM public.users WHERE id = '[AUTH_UID_AQUI]';
  4. Se retornar 0 linhas: Usuário em auth.users MAS NÃO em public.users
  5. Se retornar 1 linha: Usuário existe

Opção B: Verificar se Trigger está ativo
  1. Execute: SELECT * FROM information_schema.triggers 
     WHERE trigger_name = 'set_clinic_id_on_insert';
  2. Se retornar 1 linha: Trigger ativo ✅
  3. Se retornar 0 linhas: Trigger não foi criado


Opção C: Testar Trigger manualmente
  1. Execute:
     SELECT public.set_appointments_clinic_id();
  2. Ver mensagem de erro detalhada
