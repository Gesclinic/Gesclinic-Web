TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════════════

❌ SQL Execution Failed?
   Error: "Function already exists"
   → Probably SQL was already applied
   → Check tables exist: see Step 3 - Verify

❌ Changes not appearing in "Histórico de Mudanças"?
   → Verify trigger is enabled:
      SELECT trigger_name FROM information_schema.triggers 
      WHERE trigger_name = 'trg_log_appointment_changes';
   → Should return 1 row
   → If not, re-run SQL from Step 2

❌ Build errors in development?
   → Run: npm install
   → Run: npm run build
   → Check console for errors

❌ Realtime not working?
   → Verify Realtime enabled in Supabase console
   → Check browser console (F12) for errors
   → Try refreshing page
