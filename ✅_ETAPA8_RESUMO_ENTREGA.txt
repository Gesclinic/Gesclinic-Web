🚀 COMO USAR - QUICK START

════════════════════════════════════════════════════════════════════════════════

PASSO 1: Executar Migration
   1. Copie o SQL: supabase/migrations/20260523_ETAPA8_ALERTAS_AUTOMACOES.sql
   2. Cole no Supabase SQL Editor
   3. Clique RUN

PASSO 2: Adicionar NotificationBell
   1. Abra src/components/layout/Navbar.jsx
   2. Importe: import NotificationBell from '@/components/NotificationBell'
   3. Adicione na navbar: <NotificationBell />

PASSO 3: Adicionar Rota AlertCenter
   1. Abra src/AppRoutes.jsx
   2. Importe: import AlertCenter from '@/pages/financeiro/AlertCenter'
   3. Adicione rota: <Route path="alerts" element={<AlertCenter />} />

PASSO 4: Adicionar Menu
   1. Abra src/constants/menu.js
   2. Adicione item: { label: 'Alertas', path: '/clinica/financeiro/alerts' }

PASSO 5: Testar
   1. npm run dev
   2. Vá para http://localhost:3000/clinica/financeiro/alerts
   3. Clique "Verificar Alertas Agora" para testar
