PASSO 2: ADICIONAR ROTAS
═════════════════════════════════════════════════════════════════════════════

Localize a seção de rotas aninhadas de AGENDA em src/AppRoutes.jsx

Procure por algo como:

```jsx
<Route path="/clinica/agenda/*" element={<AgendaLayout />}>
  {/* ... outras rotas de agenda ... */}

```

ADICIONE estas 2 rotas DENTRO desse bloco:

```jsx

<Route path="recepcao/test" element={<ReceptionTestPage />} />
```


EXEMPLO COMPLETO (estrutura inteira):

```jsx

  {/* Rotas públicas */}
```

SE USAR LAZY LOADING (opcional, para otimizar bundle)
═════════════════════════════════════════════════════════════════════════════

Se preferir lazy load (carrega página apenas quando acessar):

```jsx
const ReceptionPage = lazy(() =>
  import('@/pages/Reception/ReceptionPage').then((m) => ({
    default: m.ReceptionPage,
  }))
);

const ReceptionTestPage = lazy(() =>
  import('@/pages/Reception/ReceptionTestPage').then((m) => ({
    default: m.ReceptionTestPage,
  }))
);
```

Depois nas rotas:

```jsx
<Route 
  path="recepcao" 
  element={
    <Suspense fallback={<div>Carregando...</div>}>
      <ReceptionPage />
    </Suspense>
  } 
/>
<Route 
  path="recepcao/test" 
  element={
    <Suspense fallback={<div>Carregando...</div>}>
      <ReceptionTestPage />
    </Suspense>
  } 
/>
```

TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════════

❌ "Cannot find module '@/pages/Reception/ReceptionPage'"

Solução:
  1. Verifique se o arquivo existe em: src/pages/Reception/ReceptionPage.tsx
  2. Verifique o alias @ em vite.config.js (deve apontar para ./src)
  3. Revise o path: deve ser @/pages/Reception/ReceptionPage (sem .tsx)


❌ "ReceptionPage is not exported"

Solução:
  1. Abra: src/pages/Reception/ReceptionPage.tsx
  2. Verifique se tem: export function ReceptionPage() { ... }
  3. Se não tem, adicione export


❌ Página não carrega, mostra branco

Solução:
  1. Abra console (F12)
  2. Procure por erros em vermelho
  3. Verifique se ReceptionPage.tsx tem erro de sintaxe
  4. Tente fazer hard refresh (Ctrl+Shift+R)


❌ "Cannot find clinic context"

Solução:
  1. ReceptionPage precisa estar dentro de AppLayout (que tem ClinicProvider)
  2. Verifique se route está aninhada corretamente em /clinica
