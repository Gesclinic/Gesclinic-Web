❌ ERR_CONNECTION_REFUSED (-102)

Isso significa:
  - Nenhum servidor está rodando na porta 3000
  - npm run dev ainda não foi executado
  - Ou o servidor foi interrompido

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

SOLUÇÃO: INICIAR O SERVIDOR
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

PASSO 1: Abra o Terminal
──────────────────────────

1. No VS Code, pressione:
   Ctrl + ` (backtick/crase)
   
   Ou vá para:
   → Terminal → New Terminal

2. Um terminal deve abrir na parte inferior

PASSO 2: Verifique que está no diretório correto
─────────────────────────────────────────────────

O terminal deve mostrar:
  C:\Users\ferna\Desktop\Projeto Gesclinic Web>

Se não estiver, execute:
  cd "C:\Users\ferna\Desktop\Projeto Gesclinic Web"

PASSO 3: Inicie o servidor
──────────────────────────

Execute este comando:

┌─────────────────────────────────────────────────────────────────────────┐
│                                                                         │
│ npm run dev                                                             │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘

PASSO 4: Aguarde a mensagem de sucesso
──────────────────────────────────────

Você deve ver mensagens como:

  VITE v5.0.0 ready in XXX ms

  ➜  Local:     http://localhost:3000/
  ➜  Network:   use --host to expose

Quando ver isso, o servidor está ONLINE! ✅

PASSO 5: Acesse a URL
─────────────────────

Agora você pode:

1. Abra seu navegador

2. Vá para: http://localhost:3000/clinica/agenda

3. Ou clique no link que aparece no terminal

ERROS COMUNS DURANTE npm run dev
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

ERRO 1: "npm: command not found"
────────────────────────────────

Significa: Node.js não está instalado

Solução:
  1. Instale Node.js: https://nodejs.org/
  2. Reinicie o VS Code
  3. Execute: npm run dev

ERRO 2: "ENOENT: no such file or directory"
──────────────────────────────────────────

Significa: Você não está no diretório correto

Solução:
  1. Verifique o diretório:
     pwd (ou cd no terminal)
  
  2. Vá para a pasta do projeto:
     cd "C:\Users\ferna\Desktop\Projeto Gesclinic Web"
  
  3. Execute: npm run dev

ERRO 3: "Port 3000 is already in use"
────────────────────────────────────

Significa: Outra aplicação usa a porta 3000

Solução A: Feche a outra aplicação
  1. Procure outra aba/janela do navegador ou VS Code
  2. Feche

Solução B: Use outra porta
  1. Execute: npm run dev -- --port 3001
  2. Acesse: http://localhost:3001/clinica/agenda

ERRO 4: "Cannot find module"
───────────────────────────

Significa: Dependências não foram instaladas

Solução:
  1. Execute: npm install
  2. Aguarde terminar (~1-2 minutos)
  3. Execute: npm run dev

ERRO 5: "VITE_SUPABASE_URL is not defined"
──────────────────────────────────────────

Significa: Arquivo .env não está configurado

Solução:
  1. Abra: .env (arquivo oculto na raiz do projeto)
  2. Adicione suas credenciais Supabase:
     VITE_SUPABASE_URL=https://seu-projeto.supabase.co
     VITE_SUPABASE_ANON_KEY=sua-chave-aqui
  3. Salve o arquivo
  4. Execute: npm run dev
