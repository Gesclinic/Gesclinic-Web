## 🔄 FLUXO DE FUNCIONAMENTO

```
┌──────────────────────────────────────────────────────────────────────────┐
│                         USUÁRIO ABRE AGENDA                              │
└──────────────────────────┬───────────────────────────────────────────────┘
                           │
                           ↓
        ┌──────────────────────────────────────────┐
        │ generateEncaixeSuggestions()              │
        │ Analisa: Slots, Faltas, Ocupação, Receita│
        └──────────────────────┬───────────────────┘
                               │
                ┌──────────────┼──────────────┐
                ↓              ↓              ↓
         ┌──────────┐   ┌──────────┐   ┌──────────┐
         │ SLOT     │   │ NO_SHOW  │   │ PROFIS   │
         │ LIVRE    │   │ (Falta)  │   │ OCIOSO   │
         └──────────┘   └──────────┘   └──────────┘
                
                           (E MAIS)
                             │
                ┌────────────┴────────────┐
                ↓                         ↓
         ┌────────────────┐     ┌─────────────────┐
         │ AGENDA CRÍTICA │     │ ORDEM por PRIO  │
         │ (Ocupação <40%)│     │ ALTA→MEDIA→BAIXA│
         └────────────────┘     └─────────────────┘
                
                           ↓
        ┌──────────────────────────────────────────┐
        │ Retorna: Array de Sugestões              │
        │ [{ type, prioridade, acao, mensagem }]  │
        └──────────────────────┬───────────────────┘
                               │
                               ↓
        ┌──────────────────────────────────────────┐
        │ Renderizar em AgendaSuggestions          │
        │ - Cards com ícones                       │
        │ - Cores por prioridade                   │
        │ - Botões de ação                         │
        └──────────────────────┬───────────────────┘
                               │
                               ↓
        ┌──────────────────────────────────────────┐
        │ Usuário clica em ação                    │
        │ (VER_LISTA_ESPERA, CRIAR_ENCAIXE, etc)  │
        └──────────────────────┬───────────────────┘
                               │
                               ↓
        ┌──────────────────────────────────────────┐
        │ logSuggestionAction() → Auditoria        │
        │ (Registra em suggestion_audit_logs)      │
        └──────────────────────┬───────────────────┘
                               │
                               ↓
        ┌──────────────────────────────────────────┐
        │ Callback dispara ação                    │
        │ (Modal, form, contato, etc)              │
        └──────────────────────┬───────────────────┘
                               │
                               ↓
        ┌──────────────────────────────────────────┐
        │ setRefreshTrigger(prev => prev + 1)      │
        │ → Recarrega sugestões                    │
        └──────────────────────────────────────────┘
```
