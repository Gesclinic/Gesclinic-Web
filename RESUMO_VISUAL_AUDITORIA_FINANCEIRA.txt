## FLUXO DE DADOS

### 1️⃣ Criar Conta a Receber

```
financeApi.createAR(appointmentId, payload)
    │
    ├─ INSERT INTO accounts_receivable
    │
    └─ auditFinancialIntegration.logReceivableCreated()
        │
        └─ logAppointmentFinancialAudit({
             appointmentId,
             financialEventType: "RECEIVABLE_CREATED",
             relatedEntity: "accounts_receivable",
             relatedEntityId: receivable.id,
             amount: receivable.amount,
             performed_by: currentUser.id,
             performed_by_role: "GESTOR",
             context: { payer_id, ... }
           })
            │
            └─ INSERT INTO appointment_financial_audit_logs
```

### 2️⃣ Registrar Pagamento

```
financeApi.updateAR(id, { status: 'received', paid_amount: X })
    │
    ├─ UPDATE accounts_receivable
    │
    └─ auditFinancialIntegration.logPaymentReceived()
        │
        └─ logAppointmentFinancialAudit({
             appointmentId,
             financialEventType: "PAYMENT_RECEIVED",
             relatedEntity: "accounts_receivable",
             amount: paid_amount,
             previousAmount: pending_amount,
             status: "received"
           })
            │
            └─ INSERT INTO appointment_financial_audit_logs
```

### 3️⃣ Calcular Repasse Médico

```
repasseMedicoApi.gerarRepasse({ clinicId, mes, ano })
    │
    ├─ CALL gerar_repasse_medico() [RPC]
    │
    └─ Para cada resultado:
        └─ auditFinancialIntegration.logRepasseCalculated()
            │
            └─ logAppointmentFinancialAudit({
                 appointmentId,
                 financialEventType: "REPASSE_CALCULATED",
                 relatedEntity: "repasse_medico",
                 amount: repasse.amount,
                 context: { professional_id, commission, ... }
               })
                │
                └─ INSERT INTO appointment_financial_audit_logs
```

### 4️⃣ Visualizar Timeline

```
AppointmentDrawer.jsx
    │
    ├─ <AppointmentFinancialAuditTimeline appointmentId={...} />
    │
    ├─ useAppointmentFinancialAudit(appointmentId)
    │    │
    │    └─ getAppointmentFinancialAuditTrail(appointmentId)
    │        │
    │        └─ SELECT * FROM appointment_financial_audit_logs
    │           WHERE appointment_id = ?
    │           ORDER BY performed_at
    │
    └─ Renderizar timeline com eventos ordenados
```

## COMPARAÇÃO: ANTES vs DEPOIS

### ❌ ANTES (Sem Auditoria)
```
User: "Quanto foi pago desse atendimento?"
Admin: 🤷 "Não sei, preciso procurar nos logs de caixa"

5 minutos depois...

Admin: "Achei que foram R$ 150, mas não tenho certeza"
User: "E quando foi pago?"
Admin: 😕 "Também não sei com precisão, o sistema não registra"
```

### ✅ DEPOIS (Com Auditoria)
```
User: "Quanto foi pago desse atendimento?"
Gestor: "Excelente pergunta! *abre drawer* 
         - Conta criada: 14/01 10:30 por João (Gestor)
         - Pagamento recebido: 14/01 15:00 por Maria (Caixa)
         - Valor: R$ 150.00
         - Método: PIX
         - Recibo: REC-001"
User: ✅ Perfeito! Temos rastreabilidade total!
```
