⚠️ POSSÍVEIS ERROS E SOLUÇÕES
════════════════════════════════════════════════════════════════════════════════

ERRO: "CheckinRecepacao is not defined"
SOLUÇÃO: Verifique se o import está correto em AppRoutes.jsx
         import CheckinRecepacao from "@/pages/clinica/agenda/views/CheckinRecepacao";

ERRO: Menu não mostra Check-in
SOLUÇÃO: Verifique se seu perfil está em roles: ["admin", "gestor", "recepcao"]

ERRO: "Nenhum agendamento para hoje"
SOLUÇÃO: Normal se não há agendamentos. Crie um agendamento de teste.

ERRO: Botões desabilitados
SOLUÇÃO: Checklist ou financeiro não está OK. Veja as mensagens vermelhas.

ERRO: npm run dev não inicia
SOLUÇÃO: 
  1. npm install
  2. Limpe cache: npm run clean:win (se Windows)
  3. Tente novamente
