❌ PROBLEMA ORIGINAL:
   "column reference 'clinic_id' is ambiguous"

📍 CAUSA RAIZ:
   Função forecast_revenue() usava referência desqualificada para clinic_id

📝 CORREÇÃO EXECUTADA:

   Arquivo: FIX_FORECAST_REVENUE.sql
   Local: Supabase SQL Editor → New Query
   Tipo: CREATE OR REPLACE FUNCTION

   Mudanças:
   ├─ Adicionado alias "ai" para tabela ar_invoices
   ├─ Qualificado todas referências: ai.clinic_id
   ├─ Qualificado: ai.created_at, ai.amount
   ├─ Qualificado: DATE(ai.created_at)
   └─ Qualificado: LAG(SUM(ai.amount))

   Resultado: ✅ EXECUTADO COM SUCESSO
