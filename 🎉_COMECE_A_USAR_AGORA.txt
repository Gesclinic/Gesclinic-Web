Exemplo 4 - Usar Hook para Custom Logic:

```tsx
import { useWaitingQueue } from '@/modules/agenda/reception';

export function CustomStats() {
  const { queue, stats, is_live } = useWaitingQueue('clinic-123');
  
  return (
    <div className="flex gap-4">
      <div>
        <span className="text-2xl font-bold">{queue.length}</span>
        <p className="text-sm text-gray-600">Na fila</p>
      </div>
      
      <div>
        <span className="text-2xl font-bold">{stats.average_wait_time_minutes}</span>
        <p className="text-sm text-gray-600">Média (min)</p>
      </div>
      
      <div>
        <span className={is_live ? 'text-green-600' : 'text-red-600'}>
          {is_live ? '🟢 AO VIVO' : '🔴 Offline'}
        </span>
      </div>
    </div>
  );
}
```

Resultado:
  ✅ Dados em tempo real
  ✅ Estatísticas live
  ✅ Status de conexão

   └─ Props: clinic_id, compact?
   └─ 4 seções principais
   └─ Realtime via React Query

2. WaitingQueuePanel
   └─ Props: clinic_id, maxItems?, showSearch?, onSelectAppointment?
   └─ Lista interativa
   └─ Search integrado

3. CheckInButton
   └─ Props: appointment_id, clinic_id, status, patient_name?, etc
   └─ Valida status 'confirmed'
   └─ Abre CheckInDialog

4. CheckInDialog
   └─ Props: appointment_id, clinic_id, patient_name?, etc
   └─ Modal de confirmação
   └─ Campo de notas

5. QueueStatusBadge
   └─ Props: tempo_espera_minutos, wait_priority, showTime?, animate?
   └─ Badge visual com cores
   └─ Animação para crítico

HOOKS:

1. useWaitingQueue(clinic_id)
   └─ Returns: { queue, stats, loading, is_live, refetch }
   └─ Realtime subscriptions
   └─ Cache com React Query

2. useCheckIn(clinic_id)
   └─ Returns: { loading, error, success, perform_checkin, reset }
   └─ Gerencia check-in
   └─ Query invalidation

3. useReceptionRealtimeSync(clinic_id)
   └─ Returns: { sync_state, on_event, off_event }
   └─ Sync cross-tab
   └─ Deduplicação

API:

1. performCheckIn(params)
   └─ Fazer check-in
   └─ Retorna sucesso/erro

2. getWaitingQueue(params)
   └─ Buscar fila
   └─ Inclui tempo_espera

3. getWaitingQueueStats(clinic_id)
   └─ Estatísticas da fila
   └─ Média, máximo, críticos

4. getReceptionOperationalData(clinic_id)
   └─ Dados operacionais
   └─ Próximo, em atendimento, etc

❌ "Fila não atualiza em tempo real"
   ✅ Verifique se Realtime está habilitado: ALTER PUBLICATION...
   ✅ Verifique conexão Supabase
   ✅ Veja console para erros de conexão

❌ "RLS error: relation user_clinic_roles does not exist"
   ✅ Você pode usar a versão v2_simplificado.sql que foi executada
   ✅ Depois ajuste com RLS correto conforme sua estrutura

❌ "Componente não renderiza dados"
   ✅ Verifique clinic_id (deve ser UUID válido)
   ✅ Verifique se tem dados em appointments
   ✅ Veja network tab para erros de API

❌ "Performance lenta com muitos pacientes"
   ✅ Use maxItems para limitar (default 50)
   ✅ WaitingQueuePanel já tem virtualization ready
   ✅ Adicione índices no Supabase se necessário
