SE ENCONTRAR ERROS
───────────────────

Erro de Autenticação?
   1. Verifique localStorage (DevTools → Application → LocalStorage)
   2. Certifique-se de estar em /clinica/financeiro/*
   3. Teste com: fernando medeiros / test123

Gráficos não aparecem?
   1. Abra DevTools → Console
   2. Verifique se há erros RPC
   3. Verifique se as views retornam dados:
      SELECT * FROM v_kpi_mensais WHERE clinic_id = '...'

Dados faltando?
   1. Verifique a clínica_id nas queries
   2. Confira se há RLS (Row Level Security) ativo
   3. Execute: SELECT current_setting('request.jwt.claims')
