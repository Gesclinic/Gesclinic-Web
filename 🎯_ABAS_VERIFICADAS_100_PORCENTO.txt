## 🔗 INTEGRAÇÃO COM API

### **Fluxo de Dados:**
```
User (Frontend)
    ↓ (fetch com JWT)
API Client (Supabase)
    ↓ (parameterized query)
Database (PostgreSQL)
    ↓ (RLS policy check)
Dados filtrados por clinic_id
    ↓ (response)
React Query Cache
    ↓ (deduplication)
Component Update
    ↓ (Toast notification)
User sees data ✅
```

### **Error Handling:**
```
API Error
    ↓
Try/Catch bloco
    ↓
isRetryableError() check
    ↓ (Yes)
Retry com exponential backoff
    ↓ (Sucesso)
Dados carregados ✅
    ↓ (Falha permanente)
Toast notification (erro amigável)
    ↓
User vê mensagem clara
```
