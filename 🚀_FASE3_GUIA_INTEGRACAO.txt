❌ "Cannot find module ReceptionPage"
   ✅ Verifique caminho: src/pages/Reception/ReceptionPage.tsx
   ✅ Use lazy import conforme exemplo

❌ "Clinic context not available"
   ✅ Verifique se está dentro de AppLayout (que tem ClinicProvider)
   ✅ Use useClinicContext() dentro de ProtectedRoute

❌ "Dashboard não carrega dados"
   ✅ Verifique clinic_id (deve ser UUID válido)
   ✅ Verifique se tem dados em appointments
   ✅ Veja console para erros de API

❌ "Realtime não funciona"
   ✅ Verifique se migration foi executada no Supabase
   ✅ Verifique ALTER PUBLICATION supabase_realtime
   ✅ Tente F5 para recarregar
